Overview

This Android application demonstrates the use of Intents (Implicit and Explicit) and Material Design components. It consists of a secure Login Screen and a Dashboard that allows users to perform various system actions.
Features
1. Authentication (Explicit Intent)

    Login Screen: A beautifully designed Material3 login card.
    Validation: Basic email and password verification.
    Navigation: Redirects to the Main Activity upon successful login.

2. Dashboard Actions (Implicit Intents)

    Web Browsing: Open any URL in the system browser.
    Phone Calling: Dial numbers directly from the app.
    Call Logs: View system call history.
    Gallery: Open the system image gallery.
    Camera: Launch the camera to capture photos.
    Alarm: Set reminders/alarms.

Tech Stack

    Language: Kotlin
    UI Framework: XML with Material Design 3 (M3)
    Architecture: ConstraintLayout for responsive design
    Build System: Gradle (Kotlin DSL - .kts)
    Min SDK: 24
    Target SDK: 34/37

How to Run

    Clone the repository or download the source code.
    Open the project in Android Studio (Ladybug or later).
    Sync the project with Gradle files.
    Run the app on an Emulator or a Physical Device.
